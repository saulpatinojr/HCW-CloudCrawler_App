# NNNN. Title

- **Status:** Proposed | Accepted | Rejected | Superseded by NNNN | Deprecated
- **Date:** YYYY-MM-DD
- **Owners:** names or teams accountable for the decision
- **Issue:** link to the decision issue

## Context

The problem, requirement, constraint or change that requires a decision.

## Decision

What was decided and the intended end state.

## Alternatives considered

| Alternative | Benefits | Drawbacks | Reason not selected |
| --- | --- | --- | --- |
| | | | |

## Consequences

Business, security, reliability, cost, performance, compliance, data and
operational effects, positive and negative.

## Validation

Implementation owner, acceptance criteria and the evidence that shows the
decision is in effect.

## Rollback or revisit trigger

How the decision can be reversed, or the evidence that would reopen it.
